# EarlyCue

Marketing site for EarlyCue (earlycue.com), built with Astro + Tailwind + React, mirroring the zishansami.com stack.

## Develop

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deployed via the Vercel adapter. Replace BOOKING_LINK in src/components/Hero.astro and src/components/CtaFinal.astro before shipping.
